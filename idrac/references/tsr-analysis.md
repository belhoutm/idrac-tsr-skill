## Overview

A Technical Support Report (TSR) is a comprehensive diagnostic package generated by Dell iDRAC that contains system information, hardware inventory, logs, and configuration data. TSRs are essential for troubleshooting hardware issues and performing system health assessments.

### TSR Structure

TSRs are typically distributed as ZIP files containing multiple XML files and log data:

```
tsr_report.zip
├── support.xml          # Main support information
├── system.xml           # System hardware inventory
├── firmware.xml         # Firmware version information
├── sel.xml              # System Event Log
├── lclog.xml            # Lifecycle Controller logs
├── storage.xml          # Storage configuration
├── network.xml          # Network configuration
├── bios.xml             # BIOS configuration
├── power.xml            # Power management data
├── temperature.xml      # Temperature readings
├── fan.xml              # Fan status
├── memory.xml           # Memory information
├── processor.xml        # Processor information
└── logs/                # Additional log files
    ├── dset.log
    ├── racadm.log
    └── ...
```

## Generating TSR Reports

### Via iDRAC Web Interface

1. Log into iDRAC web interface
2. Navigate to **Support** → **Support Assistance**
3. Click **Generate Technical Support Report**
4. Wait for generation to complete
5. Download the ZIP file

### Via racadm CLI

```bash
# Generate TSR report
racadm -r <idrac-ip> -u <YOUR_USERNAME> -p <YOUR_PASSWORD> techsupreport export

# Specify output location
racadm -r <idrac-ip> -u <YOUR_USERNAME> -p <YOUR_PASSWORD> techsupreport export -f /path/to/output.zip
```

## TSR Analysis Workflows

### Basic System Information Extraction

**Purpose:** Extract basic system information for inventory and documentation.

**Steps:**
1. Extract TSR ZIP file
2. Parse support.xml for system overview
3. Parse system.xml for hardware inventory
4. Extract service tag, model, serial number
5. Compile system summary

**Python Example:**
```python
import zipfile
import xml.etree.ElementTree as ET
from datetime import datetime

class TSRExtractor:
    def __init__(self, tsr_file):
        self.tsr_file = tsr_file
        self.temp_dir = tempfile.mkdtemp()
        self.extract_tsr()
    
    def extract_tsr(self):
        """Extract TSR ZIP file"""
        with zipfile.ZipFile(self.tsr_file, 'r') as zip_ref:
            zip_ref.extractall(self.temp_dir)
    
    def get_system_info(self):
        """Extract basic system information"""
        support_xml = f"{self.temp_dir}/support.xml"
        tree = ET.parse(support_xml)
        root = tree.getroot()
        
        sys_info = {
            'service_tag': root.find('.//ServiceTag').text,
            'model': root.find('.//Model').text,
            'serial_number': root.find('.//SerialNumber').text,
            'bios_version': root.find('.//BIOSVersion').text,
            'idrac_version': root.find('.//iDRACVersion').text,
            'generation_date': root.find('.//GenerationDate').text
        }
        return sys_info
    
    def get_hardware_inventory(self):
        """Extract hardware inventory"""
        system_xml = f"{self.temp_dir}/system.xml"
        tree = ET.parse(system_xml)
        root = tree.getroot()
        
        inventory = {
            'processors': [],
            'memory': [],
            'storage': []
        }
        
        # Extract processors
        for proc in root.findall('.//Processor'):
            inventory['processors'].append({
                'id': proc.find('ID').text,
                'manufacturer': proc.find('Manufacturer').text,
                'model': proc.find('Model').text,
                'cores': proc.find('Cores').text,
                'status': proc.find('Status').text,
                'health': proc.find('Health').text
            })
        
        # Extract memory
        for dimm in root.findall('.//DIMM'):
            inventory['memory'].append({
                'id': dimm.find('ID').text,
                'manufacturer': dimm.find('Manufacturer').text,
                'capacity': dimm.find('Capacity').text,
                'type': dimm.find('Type').text,
                'status': dimm.find('Status').text,
                'health': dimm.find('Health').text
            })
        
        return inventory
```

### Error Detection and Analysis

**Purpose:** Identify critical errors, warnings, and hardware failures from system logs.

**Steps:**
1. Parse sel.xml for System Event Log entries
2. Parse lclog.xml for Lifecycle Controller logs
3. Filter entries by severity (Critical, Warning, Info)
4. Categorize errors by component and type
5. Generate error summary with recommendations

**Python Example:**
```python
class TSRErrorAnalyzer:
    def __init__(self, tsr_file):
        self.tsr_file = tsr_file
        self.temp_dir = tempfile.mkdtemp()
        self.extract_tsr()
    
    def analyze_errors(self):
        """Analyze system logs for errors"""
        errors = {
            'critical': [],
            'warning': [],
            'info': []
        }
        
        # Analyze SEL
        sel_xml = f"{self.temp_dir}/sel.xml"
        tree = ET.parse(sel_xml)
        root = tree.getroot()
        
        for entry in root.findall('.//Entry'):
            severity = entry.find('Severity').text
            error_data = {
                'timestamp': entry.find('Timestamp').text,
                'category': entry.find('Category').text,
                'message': entry.find('Message').text,
                'component': entry.find('Component').text if entry.find('Component') is not None else 'Unknown'
            }
            
            if severity == 'Critical':
                errors['critical'].append(error_data)
            elif severity == 'Warning':
                errors['warning'].append(error_data)
            else:
                errors['info'].append(error_data)
        
        return errors
    
    def get_error_summary(self):
        """Generate error summary with recommendations"""
        errors = self.analyze_errors()
        
        summary = {
            'total_critical': len(errors['critical']),
            'total_warning': len(errors['warning']),
            'total_info': len(errors['info']),
            'recommendations': []
        }
        
        # Generate recommendations based on errors
        for error in errors['critical']:
            if 'Power' in error['category']:
                summary['recommendations'].append(
                    f"CRITICAL: Power supply issue detected for {error['component']}. "
                    "Check power supply and replace if necessary."
                )
            elif 'Temperature' in error['category']:
                summary['recommendations'].append(
                    f"CRITICAL: Temperature threshold exceeded for {error['component']}. "
                    "Check cooling system and ambient temperature."
                )
        
        for error in errors['warning']:
            if 'Memory' in error['category']:
                summary['recommendations'].append(
                    f"WARNING: Memory issue detected for {error['component']}. "
                    "Consider running memory diagnostics."
                )
        
        return summary
```

### Firmware Version Analysis

**Purpose:** Check firmware versions, identify outdated components, and recommend updates.

**Steps:**
1. Parse firmware.xml for component firmware versions
2. Compare against latest available versions
3. Identify outdated or incompatible firmware
4. Generate firmware update recommendations

**Python Example:**
```python
class TSRFirmwareAnalyzer:
    def __init__(self, tsr_file):
        self.tsr_file = tsr_file
        self.temp_dir = tempfile.mkdtemp()
        self.extract_tsr()
    
    def get_firmware_versions(self):
        """Extract firmware versions for all components"""
        firmware_xml = f"{self.temp_dir}/firmware.xml"
        tree = ET.parse(firmware_xml)
        root = tree.getroot()
        
        firmware_info = []
        for component in root.findall('.//Component'):
            firmware_info.append({
                'name': component.find('Name').text,
                'version': component.find('Version').text,
                'release_date': component.find('ReleaseDate').text,
                'status': component.find('Status').text
            })
        
        return firmware_info
    
    def check_firmware_compatibility(self):
        """Check firmware compatibility between components"""
        firmware = self.get_firmware_versions()
        
        # Get specific versions
        bios_version = next((f['version'] for f in firmware if f['name'] == 'BIOS'), None)
        idrac_version = next((f['version'] for f in firmware if f['name'] == 'iDRAC'), None)
        
        compatibility_issues = []
        
        # Check for known compatibility issues
        if bios_version and idrac_version:
            if self._is_incompatible_firmware(bios_version, idrac_version):
                compatibility_issues.append(
                    f"BIOS version {bios_version} may be incompatible with iDRAC version {idrac_version}"
                )
        
        return {
            'firmware': firmware,
            'compatibility_issues': compatibility_issues
        }
    
    def _is_incompatible_firmware(self, bios_version, idrac_version):
        """Check for known firmware compatibility issues"""
        # Add known incompatibility rules
        incompatible_combinations = [
            ('2.6.0', '4.30.00.00'),
            ('2.7.0', '4.35.00.00')
        ]
        return (bios_version, idrac_version) in incompatible_combinations
```

### Health Assessment

**Purpose:** Generate comprehensive health assessment based on system metrics and logs.

**Steps:**
1. Extract system health indicators from all XML files
2. Analyze temperature, power, fan, and component health
3. Identify degraded or failed components
4. Generate overall health score and recommendations

**Python Example:**
```python
class TSRHealthAnalyzer:
    def __init__(self, tsr_file):
        self.tsr_file = tsr_file
        self.temp_dir = tempfile.mkdtemp()
        self.extract_tsr()
    
    def assess_health(self):
        """Comprehensive health assessment"""
        health_assessment = {
            'overall_health': 'OK',
            'component_health': {},
            'health_score': 100,
            'issues': [],
            'recommendations': []
        }
        
        # Check processor health
        processor_health = self._check_processor_health()
        health_assessment['component_health']['processors'] = processor_health
        
        # Check memory health
        memory_health = self._check_memory_health()
        health_assessment['component_health']['memory'] = memory_health
        
        # Check storage health
        storage_health = self._check_storage_health()
        health_assessment['component_health']['storage'] = storage_health
        
        # Check power health
        power_health = self._check_power_health()
        health_assessment['component_health']['power'] = power_health
        
        # Check temperature health
        temp_health = self._check_temperature_health()
        health_assessment['component_health']['temperature'] = temp_health
        
        # Calculate overall health score
        health_assessment['health_score'] = self._calculate_health_score(health_assessment)
        
        # Determine overall health status
        if health_assessment['health_score'] >= 90:
            health_assessment['overall_health'] = 'OK'
        elif health_assessment['health_score'] >= 70:
            health_assessment['overall_health'] = 'Warning'
        else:
            health_assessment['overall_health'] = 'Critical'
        
        return health_assessment
    
    def _check_processor_health(self):
        """Check processor health"""
        system_xml = f"{self.temp_dir}/system.xml"
        tree = ET.parse(system_xml)
        root = tree.getroot()
        
        processors = []
        for proc in root.findall('.//Processor'):
            health = proc.find('Health').text
            processors.append({
                'id': proc.find('ID').text,
                'health': health
            })
        
        failed_processors = [p for p in processors if p['health'] != 'OK']
        return {
            'status': 'OK' if not failed_processors else 'Critical',
            'processors': processors,
            'failed_count': len(failed_processors)
        }
    
    def _check_memory_health(self):
        """Check memory health"""
        system_xml = f"{self.temp_dir}/system.xml"
        tree = ET.parse(system_xml)
        root = tree.getroot()
        
        dimms = []
        for dimm in root.findall('.//DIMM'):
            health = dimm.find('Health').text
            dimms.append({
                'id': dimm.find('ID').text,
                'health': health
            })
        
        failed_dimms = [d for d in dimms if d['health'] != 'OK']
        return {
            'status': 'OK' if not failed_dimms else 'Warning',
            'dimms': dimms,
            'failed_count': len(failed_dimms)
        }
    
    def _calculate_health_score(self, health_assessment):
        """Calculate overall health score based on component health"""
        score = 100
        
        # Deduct points for failed components
        for component, data in health_assessment['component_health'].items():
            if data['status'] == 'Critical':
                score -= 20
            elif data['status'] == 'Warning':
                score -= 10
        
        return max(0, score)
```

### Comparative Analysis

**Purpose:** Compare TSRs from different time periods to identify trends and changes.

**Steps:**
1. Load multiple TSR files from different dates
2. Extract key metrics from each TSR
3. Compare firmware versions, configurations, and health status
4. Identify changes and trends over time
5. Generate trend analysis report

**Python Example:**
```python
class TSRComparator:
    def __init__(self, tsr_files):
        self.tsr_files = tsr_files
        self.extractors = [TSRExtractor(tsr) for tsr in tsr_files]
    
    def compare_firmware_versions(self):
        """Compare firmware versions across TSRs"""
        comparison = {
            'bios_versions': [],
            'idrac_versions': [],
            'changes': []
        }
        
        for extractor in self.extractors:
            firmware = extractor.get_firmware_versions()
            bios = next((f['version'] for f in firmware if f['name'] == 'BIOS'), None)
            idrac = next((f['version'] for f in firmware if f['name'] == 'iDRAC'), None)
            
            comparison['bios_versions'].append(bios)
            comparison['idrac_versions'].append(idrac)
        
        # Identify changes
        if len(set(comparison['bios_versions'])) > 1:
            comparison['changes'].append('BIOS version changed')
        if len(set(comparison['idrac_versions'])) > 1:
            comparison['changes'].append('iDRAC version changed')
        
        return comparison
    
    def compare_health_status(self):
        """Compare health status across TSRs"""
        health_comparison = []
        
        for extractor in self.extractors:
            analyzer = TSRHealthAnalyzer(extractor.tsr_file)
            health = analyzer.assess_health()
            health_comparison.append({
                'date': extractor.get_system_info()['generation_date'],
                'health_score': health['health_score'],
                'overall_health': health['overall_health']
            })
        
        return health_comparison
```

## Automated Diagnostic Workflows

### Pre-Support Ticket Analysis

**Purpose:** Generate comprehensive analysis before creating Dell support ticket.

**Steps:**
1. Extract TSR and parse all components
2. Run full health assessment
3. Identify critical errors and warnings
4. Check firmware compatibility
5. Generate support ticket summary with all relevant information

**Python Example:**
```python
class TSRSupportAnalyzer:
    def __init__(self, tsr_file):
        self.tsr_file = tsr_file
        self.extractor = TSRExtractor(tsr_file)
        self.error_analyzer = TSRErrorAnalyzer(tsr_file)
        self.health_analyzer = TSRHealthAnalyzer(tsr_file)
        self.firmware_analyzer = TSRFirmwareAnalyzer(tsr_file)
    
    def generate_support_summary(self):
        """Generate comprehensive support ticket summary"""
        summary = {
            'system_info': self.extractor.get_system_info(),
            'health_assessment': self.health_analyzer.assess_health(),
            'error_analysis': self.error_analyzer.analyze_errors(),
            'firmware_info': self.firmware_analyzer.get_firmware_versions(),
            'recommendations': []
        }
        
        # Compile recommendations
        if summary['health_assessment']['overall_health'] != 'OK':
            summary['recommendations'].append(
                f"System health is {summary['health_assessment']['overall_health']}. "
                "Immediate attention required."
            )
        
        if summary['error_analysis']['critical']:
            summary['recommendations'].append(
                f"{len(summary['error_analysis']['critical'])} critical errors detected. "
                "Review error details for immediate action."
            )
        
        return summary
```

## Integration with Monitoring Systems

### Prometheus Integration

```python
def export_tsr_metrics_to_prometheus(tsr_file, prometheus_url):
    """Export TSR metrics to Prometheus"""
    analyzer = TSRHealthAnalyzer(tsr_file)
    health = analyzer.assess_health()
    
    metrics = []
    
    # Export health score
    metrics.append({
        'name': 'dell_idrac_health_score',
        'value': health['health_score'],
        'labels': {
            'service_tag': analyzer.extractor.get_system_info()['service_tag']
        }
    })
    
    # Export component health
    for component, data in health['component_health'].items():
        metrics.append({
            'name': f'dell_idrac_component_health',
            'value': 1 if data['status'] == 'OK' else 0,
            'labels': {
                'component': component,
                'service_tag': analyzer.extractor.get_system_info()['service_tag']
            }
        })
    
    # Send to Prometheus
    for metric in metrics:
        send_to_prometheus(prometheus_url, metric)
```
